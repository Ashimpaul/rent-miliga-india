# RentMiliga - Rental Listings India

Find and post rental listings across India. No signup needed.

## Project info

This project is a React-based web application for browsing and posting rental listings.

## Technologies Used

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- Supabase (Backend)
- TanStack Query (Data Fetching)
- React Router (Routing)

## Getting Started

### Prerequisites

- Node.js & npm installed

### Installation

1. Clone the repository:
   ```sh
   git clone <YOUR_GIT_URL>
   ```

2. Navigate to the project directory:
   ```sh
   cd rent-miliga-india
   ```

3. Install the necessary dependencies:
   ```sh
   npm install
   ```

4. Start the development server:
   ```sh
   npm run dev
   ```

## Features

- Browse rental listings
- Post new listings without signup
- View detailed property information
- Responsive design for mobile and desktop
